# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly.

**Do NOT** open a public GitHub issue for security vulnerabilities.

### How to Report

Please email the maintainers directly with:

- A description of the vulnerability
- Steps to reproduce it
- Potential impact and suggested fix (if any)

We aim to acknowledge reports within 48 hours and will provide a timeline for
the fix based on severity.

### What to Expect

- We will confirm the vulnerability and assess its severity.
- We will release a patch in a new version as quickly as possible.
- We will credit the reporter in the release notes (unless you prefer anonymity).

## Scope

This policy applies to the evaluation pipeline code in this repository.
The vendored upstream code at `upstream/RF-Diffusion/` is governed by its
own security policy at the upstream repository.
